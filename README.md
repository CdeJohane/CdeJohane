## 🚀 Featured projects

### 🛡️ [AgentGuard](https://github.com/CdeJohane/AgentGuard) — Guardrails for AI-agent actions

A **Python learning prototype** that checks an agent's proposed file operations before simulated execution. It uses **default-deny permissions**, explicit decision reasons, an **audit trail**, and automated tests. An optional live-model demo connects AI-generated action proposals to the same guarded execution flow.

`Python` `AI Agents` `Access Control` `Testing` `Audit Logging`
